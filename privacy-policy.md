Privacy Policy – Model Deviation Summarizer

This extension does not store any personal user data.

The extension processes user-provided text from AI chat interfaces (such as ChatGPT, Gemini, Claude, and others) to analyze response quality.

All data is processed in real-time and is not stored on any server.

Users provide their own API keys, and no API keys are stored or shared.

No personally identifiable information is collected, stored, or sold.

The extension only sends necessary text data to the backend API to generate analysis results.

Users are responsible for the content they choose to analyze.

We do not track, monitor, or profile users.
